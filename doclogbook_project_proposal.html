4. Why Upgrading AI Won't Break Anything
The app never talks to an AI model directly — it always goes through one internal gateway called the LiteLLM Proxy. Swapping models only updates that routing config.

The mobile app, web portal, and all backend code stay completely unchanged.

Faster AI, zero downtime, no App Store resubmission required.
